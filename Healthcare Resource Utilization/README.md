# Healthcare Resource Utilization & Patient Insights Dashboard

## Project Overview
This project analyzes healthcare operational data to uncover insights related to patient admissions, treatment costs, department performance, and resource utilization using Python, MySQL, and Power BI.

## Key Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- SQL-based KPI Analysis
- Interactive Power BI Dashboard
- Healthcare Trend & Resource Utilization Analysis

## Tools & Technologies 
- Python
  - Pandas
  - NumPy
  - Matplotlib
  - Seaborn
- Power BI
- Microsoft Excel
- Jupyter Notebook
- CSV & Excel Files (for data storage)

## KPIs Analyzed
- Patient Admissions
- Treatment Costs
- Department-wise Patient Load
- Bed Occupancy Trends
- Readmission Analysis
